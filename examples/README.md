# 打印样例

以下文件已使用v1.0.1重新生成，字段标题统一左对齐。样例使用技能包内的300个常见单词，供了解版式。音标是示例输入的一部分，实际使用时不会自动补充用户材料中缺少的字段。

| 方案 | Excel 家长答案表（仅中英文、双词对版） | PDF 汉译英练习册 |
| --- | --- | --- |
| 每天新增5词 | [下载总表](300-words-5-per-day/单词总表.xlsx) | [下载练习册](300-words-5-per-day/艾宾浩斯复习打印册.pdf) |
| 每天新增10词 | [下载总表](300-words-10-per-day/单词总表.xlsx) | [下载练习册](300-words-10-per-day/艾宾浩斯复习打印册.pdf) |

5词方案：60组、89天、每日峰值25词，PDF35页。10词方案：30组、59天、每日峰值50词，PDF23页。所有练习册日期留空。

[下载9份自适应排版测试样例](adaptive-layout-samples.zip)：覆盖中英双字段、仅加词性、仅加音标、完整四字段，各5词/10词分组，另有同页混合字段样例。压缩包内含测试说明。

总表打印选择A4纵向；练习册选择A4横向。使用文件内分页设置，先看打印预览。Excel的实际字体替换可能随电脑和办公软件变化。
