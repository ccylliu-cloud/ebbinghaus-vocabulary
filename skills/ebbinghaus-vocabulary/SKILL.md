# 艾宾浩斯式单词复习

为家长输出两份文件：`单词总表.xlsx` 和 `艾宾浩斯复习打印册.pdf`。本地排期、排版和导出不调用付费 API。识别由当前会话的视觉/阅读能力完成，也可用本地 Tesseract 辅助；不把本 Skill 免费等同于宿主平台免费。

运行前检查可用的 Python 3.10+ 和 `requirements.txt` 依赖，优先使用宿主已有环境。下文 `scripts/run.sh` 是 macOS/Linux 快捷入口；Windows 或普通 Python 环境用 `python scripts/vocab.py` 替换它（测试用 `python scripts/test_vocab.py`）。选择实际可用的 Python 命令，详见运行说明。

## 从材料到词表

1. 读取用户上传的材料。图片直接查看；PDF逐页查看词表区域，扫描页需要视觉识别或本地 OCR。Word/Excel/EPUB 可先执行 `scripts/vocab.py extract 输入文件 --out 工作目录/提取文本.txt`。提取文本仅是草稿，不能未经复核直接当作识别结果。支持格式、依赖和字段见 [运行说明](references/usage.md)。
2. 按原文顺序整理成 JSON 数组。必需字段是 `english`、`chinese`；可选字段是 `ipa`、`pos`，原资料没有时省略键，不自动补充。兼容旧数据的空字符串，但会归一化为缺省。原资料已有音标/词性时忠实保留，尤其不要擅自改换音标口音。不要把教材标题、例句混入词条，保留复数、短语和教材释义，不改成词根。完全相同的记录自动去重，同词不同义保留并报告。缺少英文/中文或读不清的词必须核对，不能编造；`needs_review: true` 会阻止正式导出，解决后删除。**只有用户明确要求补音标时才问英式还是美式**；已指定口音就沿用。补充内容须有依据并与原文区分。不主动询问是否补音标/词性。
3. 用户只上传照片或文档、尚未选择方案时，先识别整理并执行 `scripts/run.sh compare 工作目录/词表.json`，按本次实际词数同时列出两个选项：**每天新增5词：X组、完整周期Y天、每日峰值Z词；每天新增10词：A组、完整周期B天、每日峰值C词**，然后追问选哪一个。不可只报理论上限25/50，不可用户未回答就擅自默认5词。等待选择期间可以继续核对材料；已有明确选择就沿用，不重复追问。**日期统一留空让家长手写，不询问开始日期、不推断今天、不生成具体日期。**
4. 用已复核 JSON 执行 `scripts/run.sh build 工作目录/词表.json --daily 5 --out 输出目录`；10词替换为10。用户输出目录只留两份成品。中间数据和可选 `--audit` 存工作目录。
5. 检查控制台统计。查看PDF前期多天共页、峰值页和最后一页；检查Excel打印预览，特别是长中文、长英文/音标、末组和页边界；不能只检查文件能打开。条件允许时用办公软件导出PDF，核对计划页数与实际页数、完整释义。修改排版脚本后运行 `scripts/run.sh test`。向家长交付两份文件和简短统计。

## 不可改变的规则

- 按输入顺序分组，每组5或10词，末组可不足。仅组号，无单词编号。
- 每组从首次学习起第1、3、7、15、30天出现，即偏移0、2、6、14、29。每天一组新词，结束新词后继续复习到最后一组第五次。完整天数 = ceil(词数/每天新增数)+29。无任务日跳过打印但不压缩 Day 或日期。
- 五次均汉译英。`第X次` 包括首次学习，不另加一轮。
- Excel：A4纵向，左右双区；组标题为“第X组”，不显示词号。字段标题（中文、英文、音标、词性）与下方内容统一左对齐。完整组填充左区后右区，不能跨区或跨页。预设打印区域、分页、页边距和缩放。它是家长答案表，优先准确、忠实、紧凑、清晰、方便查找和省纸。
- 每个组只显示实际存在的可选字段：有两项可选信息时“中文｜英文｜音标｜词性”；只有一项时为对应三列。整组都没有值的可选字段不占列；部分词缺失而组内其他词有值时，保留该列但不填造缺失值。
- 只有中英文时使用“中文｜英文｜中文｜英文”双词对并排，按原顺序先左侧自上而下、再右侧自上而下。10词=5行，5词=3行，末尾空位留白，不混入其他组。仅一个词的尾组仍保留四个物理格，右词对作为该组末尾空位。
- PDF：A4横向固定4等宽列，一列只能属于一天，一天占连续1–4列且不能跨页。剩余列不够时整天移到下一页。完整组也不能跨列。每列都有Day和手填日期空白线。只显示组/次数标题、中文与英文空白线，绝无答案、词号、勾选、掌握度、正确率。
- 保留教材的完整释义和括号中的用法说明，尤其是容易混淆的称呼词，不为排版擅自简写。Excel统一两种引擎的最终列宽，按保守可用宽度预换行、增加行高；PDF短提示左右排，超过两行的长提示改为全列宽提示、下方留默写线。英文优先按词换行，避免引入行末空格和中文行首标点。极端长度若在4列内仍放不下，程序明确报错，不缩到难以书写、不拆组、不漏词；只对相关长释义请用户确认简写。

本 MVP 是会话内 Skill 加本地生成器，不包含网站、账号系统或独立无人复核的通用 OCR。不要声称已经核验实际 Excel 打印效果，除非确实打开打印预览或用办公软件渲染检查。
