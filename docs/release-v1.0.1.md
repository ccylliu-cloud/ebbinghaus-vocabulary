# v1.0.1 · 长释义排版修复

修复教材中较长的中文释义在Excel中被截断，以及不同导出方式导致列宽和实际打印页数不一致的问题。

- 总表增加中文字段宽度，按可用宽度换行并预留足够行高；统一最终列宽和打印宽度余量。
- 中文、英文、音标、词性标题与正文统一左对齐。
- 练习册短提示继续左右排列；长提示改为整列宽度、下方默写线，保留原始用法说明。
- 英文优先按词换行，中文避免行首闭标点；不补原文缺失的音标或词性。
- 继续支持每组5/10词、字段自适应、组不拆分、列不混天和天不跨页，日期留空。

验证：15项常规测试通过；本机LibreOffice实际打印检查通过，覆盖两种导出引擎、5/10词及混合字段多页总表。实际Excel/WPS客户端与实体打印尚未复测。跨平台自动测试结果见仓库Actions。

下载通用版 `ebbinghaus-vocabulary-v1.0.1.zip` 或WorkBuddy版 `ebbinghaus-vocabulary-workbuddy-v1.0.1.zip`。已有安装可用新包替换同名Skill；自行修改过的版本请先备份。WorkBuddy包与通用版共用生成代码，尚未完成WorkBuddy客户端实机验收。
